0.5.1ТААНЫМ31 октября 2026

У проекта появилось лицо.

До этого SABAK+ жил внутри приложения. Теперь у него есть публичная главная страница: любой человек может открыть её, посмотреть, как работает дневник, и попробовать его в демонстрационном режиме.

Само приложение переехало на отдельный адрес, а главная стала витриной: с опросом, калькулятором оценки и аккуратной ссылкой для соцсетей.

Предметы, ученики, оценки. Так выглядит дневник внутри.

Достижения — вовремя.

Например, «30 дней без Н»: награда приходит сама.

Итог — понятный.

Что изменилось

Для посетителя

Можно открыть главную страницу, увидеть результаты опроса, посчитать оценку в калькуляторе и сразу перейти в демонстрационный режим.

Для тех, кто делится ссылкой

У ссылки есть изображение для соцсетей, а страницы сайта видят поисковики и лучше понимают, о чём он.

Для самого дневника

Приложение живёт на своём адресе /app. Публичные тексты говорят о продукте, а не о хакатоне.

Что исправлено

  • Ошибка при настройке базы данныхИсправлена: теперь настройка проходит без сбоя.
  • Упоминания хакатона в публичных текстахУбраны: сайт рассказывает о самом дневнике.
