# SABAK+ — MVP (команда NEXUS)

Электронный дневник нового поколения: прозрачное оценивание, ИИ-помощник для учителя, дайджест для родителя, анонимная почта, работа без интернета.
Это PWA на чистом HTML/CSS/JS (без сборки). Демо-данные хранятся в браузере.

## Что уже работает
- **Ученик:** «Сегодня важно» (слабые предметы, «сколько пятёрок до следующей оценки»), расписание, ДЗ, достижения (первая пятёрка, 30 дней подряд), аффирмация дня, анонимная почта.
- **Учитель:** журнал в 1–2 касания (оценка + «за что»), посещаемость, автосохранение, **откат**, журнал изменений «кто и когда», добавление ученика (код входа выдаётся автоматически), аналитика класса.
- **ЖАРДАМЧЫ AI:** объясняет расчёт четвертной, динамику, предупреждает о нехватке данных и возможных ошибках ввода, даёт рекомендации. **Оценок не меняет.**
- **Родитель:** «Неделя ребёнка»: дайджест, сигнал о резком падении, просроченные ДЗ.
- **Администрация:** анонимные обращения (автор не сохраняется), ученики, требующие внимания.
- **Доступность:** RU / КЫ, крупный текст (кнопка «Аа»), высокий контраст, клавиатура, работает на телефоне и ПК.
- **Offline:** кнопка ⏻ в шапке включает «офлайн (демо)»; данные уходят в очередь и синхронизируются при возвращении сети. Приложение открывается без интернета (Service Worker).

Кыргызские переводы — рабочий черновик: попросите носителя вычитать.

## Новое в версии 0.2
- **▶ Демо** (кнопка в шапке и на экране входа): сценарий для жюри на 11 шагов (~2 минуты). Сам переключает роли и делает действия; «Сбросить демо-данные» возвращает всё как было.
- **«А что если?»** на странице предмета: «хочу итог 5 — сколько пятёрок/четвёрок нужно» и «если контрольная будет 3 — что станет с итогом».
- **Переключатель ролей** в шапке (показать как: ученик / родитель / учитель / администрация) — удобно на защите.
- **Экспорт журнала в Excel (CSV)** для учителя.
- **Награды появляются сами** (всплывающее уведомление), когда ученик открывает новое достижение.

## Как обновить сайт после изменений
Загрузите изменённые файлы в репозиторий (GitHub → Add file → Upload files, одноимённые файлы заменятся) → Commit. Vercel сам выложит новую версию за ~30 секунд. На телефоне с уже установленным приложением откройте его и обновите страницу два раза (Service Worker подтягивает новую версию).

## Запуск на компьютере
```bash
cd sabak
python3 -m http.server 8000      # или: npx serve .
# открыть http://localhost:8000
```

## Выкладка на Vercel (бесплатно)
### Вариант А — через GitHub (рекомендуется)
1. Создайте репозиторий на github.com (например `sabak-plus`) и загрузите в него **содержимое папки `sabak`** (чтобы `index.html` лежал в корне репозитория):
   ```bash
   cd sabak
   git init && git add . && git commit -m "SABAK+ MVP"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/sabak-plus.git
   git push -u origin main
   ```
2. Откройте vercel.com → **Sign Up → Continue with GitHub**.
3. **Add New… → Project** → найдите `sabak-plus` → **Import**.
4. Настройки: **Framework Preset = Other**, **Build Command — пусто**, **Output Directory — пусто** (оставьте по умолчанию), **Root Directory = ./**. Нажмите **Deploy**.
5. Через ~30 секунд появится ссылка вида `https://sabak-plus.vercel.app`. Она открыта всем в интернете.
6. Каждый следующий `git push` сам обновляет сайт; у каждой ветки своя тестовая ссылка.

### Вариант Б — без GitHub, через терминал
```bash
npm i -g vercel
cd sabak
vercel          # войти, ответить на вопросы (Other, ./)
vercel --prod   # выложить как основную версию
```

## Проверка после выкладки
1. Откройте ссылку на телефоне → меню браузера → **«Установить приложение» / «На экран Домой»**.
2. Включите авиарежим → откройте SABAK+ — должен открыться.
3. DevTools → Application → Manifest и Service Workers — без ошибок.

## Облачный ИИ (необязательно)
Vercel → Project → **Settings → Environment Variables**: добавьте `ANTHROPIC_API_KEY` (и при желании `ANTHROPIC_MODEL`) → **Redeploy**. Кнопка «Спросить облачного ИИ» в карточке ученика начнёт работать. В функцию уходят только оценки без ФИО. Без ключа работает встроенный анализ.
**Ключ никогда не вставляйте в код или в публичный репозиторий.**

## Если что-то не так
- Белый экран / старая версия: Ctrl+Shift+R; на телефоне — удалить значок и установить заново (Service Worker кэширует оболочку, версия кэша в `sw.js` — `CACHE`).
- 404 на всех страницах: `index.html` лежит не в корне репозитория (Root Directory).
- Кнопка облачного ИИ пишет «не подключён»: нет `ANTHROPIC_API_KEY` или не сделан Redeploy.
- Перед защитой: не меняйте `sw.js` за час до показа; проверьте открытие на телефоне жюри по QR-коду.
