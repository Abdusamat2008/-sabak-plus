# SABAK+ — электронный дневник для школ Кыргызстана

**SABAK+** — современный школьный дневник, который работает на телефоне, планшете и компьютере, а без интернета продолжает работать и сам синхронизируется при возвращении связи.

🌐 Сайт: https://sabak-plus.vercel.app/ · 🎬 Попробовать без регистрации: кнопка «Демо» на сайте

Создатель: **muradil.ovv** (Абдусамат Мурадил)

## Для кого

| Роль | Что получает |
|---|---|
| **Ученик** | Оценки по предметам с понятным итогом, расписание, домашние задания, достижения, обращения к администрации, валюта «Алтын», школьная лента «Үн» |
| **Родитель** | Недельная сводка по ребёнку, оценки и посещаемость, «дело» ученика, уведомления, новости школы |
| **Учитель** | Быстрый журнал в два касания, причины низких оценок, план урока с домашним заданием, посещаемость, экспорт в Excel/Word/PDF, подсказки ИИ, заявки учеников |
| **Администрация** | Расписание, педагоги и ученики, доступ по приглашениям, новости школы, настройка «Алтына», модерация «Үн», журнал действий, архив учебных лет |

## Главное

- **Честные оценки.** Контрольная считается с весом ×2, итог — среднее с округлением от x,5 вверх. Ученик видит, сколько «пятёрок» нужно до желаемого итога. «Двойка» всегда ставится с причиной, и её видят ученик и родители.
- **Алтын — валюта школы.** Ученик зарабатывает за хорошие оценки, домашние задания в срок и достижения, а тратит на «отпроситься с урока или дня» (по уважительной причине и с решением учителя), пропуск ДЗ, пересдачу, привилегии и темы профиля. Можно переводить друзьям и получать награды от учителей.
- **Новости школы.** Каждая школа видит только свои новости: для всех, для учеников, родителей, педагогов или одного класса. Новости других школ закрыты.
- **«Үн» — голос школы.** Своя мини-соцсеть внутри школы: посты, фото, лайки, комментарии. Посты, фото, опросы, теги, «эхо» и комментарии. Войти можно с профилем (свой @username, тема, обложка) или анонимно — чтобы честно говорить о школьной жизни. Класс в профиле не показывается. Есть модерация.
- **Безопасность.** Школы изолированы друг от друга. Доступ только по приглашению от школы. Ученик видит только своё, родитель — только своего ребёнка, суперадмин платформы — только сводки без имён учеников.
- **Для всех.** Русский и кыргызский языки, режимы для слабовидящих (контраст, крупный текст), простой режим, работа без интернета, установка на телефон как приложение.

3. Директор регистрируется по ключу, приглашает завучей и учителей, а те — родителей и учеников.
